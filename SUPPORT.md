# Support

Thanks for using Laravel Model Validation! Here is how to get help.

## Questions & usage help

- Read the [README](README.md) &mdash; it covers installation and every feature
  with examples.
- Ask in [GitHub Discussions](https://github.com/theriddleofenigma/laravel-model-validation/discussions)
  for how-to questions and general usage help.

## Bugs & feature requests

- Search the [existing issues](https://github.com/theriddleofenigma/laravel-model-validation/issues)
  to see if it has already been reported.
- If not, open a new issue using the appropriate template and include a minimal
  reproduction.

## Security issues

Please report security vulnerabilities privately &mdash; see
[SECURITY.md](SECURITY.md). Do not open a public issue for them.
